# Slot G350 0.1.3 — audio scheduling, N64 and physical artwork

For the BATLEXP G350 already running this Slot fork.

**Boot recovery:** the owner reported a hang before Slot startup with the original 0.1.3 package. For the existing card, use `slot-g350-0.1.3-boot-recovery-update.zip` and follow `G350-0.1.3-RECOVERY.md`. It contains the same frontend, audio change and N64 core with a different boot initializer. Do not reflash the original 0.1.3 image to try to cure that hang.

## Update your current card

1. Shut down the handheld and connect its card to your computer.
2. Extract `slot-g350-0.1.3-audio-n64-update.zip`.
3. Copy **SYSTEM** and **SYSTEM.md5** onto the **PAN4ELC boot partition**, replacing those two files. Keep the pair together.
4. Safely eject the card and boot. The log should show `G350 0.1.3 startup`.

This update keeps the GAMES partition, games, labels, BIOS, saves and settings. You do not need to format or flash your current working card. The N64 core and folders are added at startup. Existing SNES/PS1 cores are unchanged.

For a fresh card, extract `slot-g350-ps1-snes-n64-0.1.3-experimental.img.zip` and flash the resulting `.img` with your usual image writer. Flashing replaces the target card's contents. First boot expands the partitions and reboots; then add your games. The G350 kernel, default panel DTB, partition layout and first-boot resize setup remain those of the working base image.

## Audio change

The supplied log recorded repeated audio starvation, with over one million missing samples in each long SNES session and hundreds of thousands in PS1 sessions, with no dropped samples. The emulator was paced by frontend display updates.

SNES, PS1 and N64 now follow the audio device's consumption at their native sample rates. A delayed redraw no longer removes a game frame's worth of audio. Games that temporarily produce no samples use their native frame period. Speaker/headphone routing, the volume fix and full-panel UI from 0.1.2 are retained.

The regression test captures audio at 48 kHz while display updates run slowly and stall for 75 ms periodically. SNES, NTSC PS1 and PAL PS1 test rates pass without inserted silent gaps. This is a software test; playback on your G350 still needs confirmation. If stutter remains, send `Slot/slot.log` after playing an affected game for about a minute.

## N64

Put uncompressed `.z64`, `.n64` or `.v64` files in **Slot/Games/N64**. No separate console BIOS is required. Labels go in **Slot/Labels/N64** with the same filename stem as the game.

N64 uses Mupen64Plus-Next, AArch64 dynamic recompilation, GLideN64 GLES2 and the HLE RSP at 320×240 internal resolution. The core is built from `libretro/mupen64plus-libretro-nx` revision `12edd2c74a517ff86dfa8cfc71ad75e4c10486d5`. It passes an original diagnostic ROM picture test and save-state round trip, plus a separate GLES orientation/context test. Commercial games and G350 performance have not been tested. **N64 is experimental; some games may run slowly or have compatibility problems.**

| G350 control | N64 control |
|---|---|
| Left stick | Analogue stick |
| D-pad | D-pad |
| A / B | A / B |
| L1 / R1 | L / R |
| L2 | Z |
| Right stick | Four C buttons |
| X / Y / R2 | C-up / C-left / C-right |
| Start | Start |
| Hold Menu | Eject game |
| Menu + X / Y | Save / load state |

N64 saves and states use their own folders. PS1 retains Menu+R2 to switch discs in an M3U playlist.

## Automatic artwork studio v3

Open `Slot-Auto-Artwork-Studio-v3.html` in Chrome or Edge, choose your **Slot folder**, and leave **Original disc / cartridge label** selected. The studio finds SNES, PS1 and N64 games and fetches their artwork automatically. Save the ready labels together, or download a ZIP and merge its Labels folder into Slot.

To replace labels made by the previous logo-only studio, enable **Replace existing labels**. Physical media artwork is preferred; logos and then covers are fallbacks. Each game shows which type and source it used. Cartridge crops are automatic; “Adjust scan crop” is available if a particular scan needs alignment. Disc scans preserve printed artwork around the hub and stay round in the frontend.

PS1 M3U playlists use Disc 1 artwork. Separately listed Disc 2/3 files select their corresponding disc. Missing or uncertain matches remain visible for correction. Coverage varies by title and region. GBA/GB/GBC continue to use the original Cart Studio.
