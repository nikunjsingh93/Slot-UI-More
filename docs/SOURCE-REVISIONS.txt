Rebuild in a fresh ARM64 Linux environment using Rust 1.96 and a Bullseye
compatible compiler/runtime. Install pkg-config, libasound2-dev, libudev-dev,
cmake, python3, e2fsprogs, fdisk, mtools, dosfstools, zip, unzip, squashfs-tools,
git and curl. Mount this bundle as /work/g350 and outputs as /outputs.
Run rebuild.sh. It modifies image files only; it never writes a physical disk.
Run tests as an ordinary user with SLOT_SILENT=1. The README and validation
notes explain the single excluded upstream timing benchmark and limitations.

The base image and March 15 system update are fetched from P4ELEC and verified
against the recorded SHA-256 values. Full P4ELEC/AmberELEC OS component source
is maintained upstream; this bundle contains the fork's frontend/core sources.
