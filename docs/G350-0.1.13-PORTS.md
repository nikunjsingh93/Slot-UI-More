# G350 0.1.13: native port controls and presentation

The owner confirmed GTA San Andreas and NFS Underground 2 working on 0.1.12. This update preserves those runtimes and all nine emulator core binaries.

Ports now use the same circular display correction and CD drive as PS1/Dreamcast. The personal update includes original PC disc scans for GTA SA and NFS U2. The source archive contains no game data or private game-linked executables.

Both the early boot image and later splash display only gray SLOT text on black. The kernel's embedded initramfs splash and Device Imager text were changed; kernel code, device tree and all other initramfs files were preserved. Updating SYSTEM alone cannot replace the early boot image: this update also supplies KERNEL and KERNEL.md5.

Native ports now inherit Slot's saved speaker/headphone volume through an ALSA software gain stage. Volume buttons adjust it during play; holding a button repeats, and pressing both together toggles mute. Speaker and headphone levels remain separate. Hold Menu alone for one second to return to Slot. Native ports use their own saves, not emulator state shortcuts.

## Installation

Use firmware/ports/install-update.ps1 with the matching update ZIP and manifest. The installer checks the connected G350 partitions and original kernel, writes SYSTEM/KERNEL with their checksum files and the two disc labels, then verifies uncached reads. It preserves other Slot files. Do not flash an entire card for this update.

## Validation

The framebuffer test confirms PS1, Dreamcast and Ports discs remain circular on the G350 panel. Supervisor tests cover Menu hold, exit status, volume taps/repeat/mute, profile switching, saved state preservation and legacy defaults. An actual ALSA softvol PCM test using the firmware's ALSA library verifies silence at zero and Slot's squared gain curve. The test substitutes the kernel mixer control; the owner subsequently reported the current setup working well. NFS U2 remains slow. All existing emulator core hashes are checked during packaging.

Build the supervisor with gcc -O2 -Wall -Wextra portwatch.c -o slot-portwatch -lasound -lm. Build slot-no-grab.c as a shared object with -shared -fPIC and -ldl. Existing Rust frontend build instructions apply. patch_system.py installs the prepared files; patch_boot_splash.py patches the original G350 KERNEL without modifying its executable code.
