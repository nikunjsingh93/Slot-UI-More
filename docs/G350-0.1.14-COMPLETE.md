# G350 0.1.14 complete image

Flash slot-g350-0.1.14.img.zip directly after extracting its .img. It combines the accepted 0.1.13 gameplay/display/volume fixes, a current frontend version marker, the matching gray SLOT KERNEL splash and a bundled official PortMaster manager. No earlier image or follow-up update is needed. An update ZIP is also available for existing matching G350 cards.

The manager is installed only if missing. Existing installations/settings remain in place, and a setup error is logged without blocking the Slot frontend. Public catalogue metadata permits offline browsing; downloads/missing runtimes still require internet. No games, BIOS, commercial disc scans, private game-linked NFS runtime, GTA APK/OBBs/libraries or saves are supplied.

All nine accepted emulator core hashes remain unchanged. The image builder validates the embedded SYSTEM/KERNEL pairs and checksum sidecars, FAT/ext4 filesystems, original bootloader/blank initial storage, first-boot resize marker, ZIP integrity and decompressed image hash. Manager provisioning/idempotence tests and native Menu/volume/audio tests pass. This newly composed fresh image's physical first boot is pending; earlier gameplay acceptance applies to its retained emulator/native base, not every port.

See G350-INSTALL-AND-PORTS.md for full instructions. Source, component notices and historical corresponding core source archives remain available. Flashing a complete image erases the target card; existing cards can use the update instead.
