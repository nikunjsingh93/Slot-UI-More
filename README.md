# Slot G350 — accepted stable 0.1.8

Owner-confirmed working BATLEXP G350 firmware source. Supports GBA/GB/GBC, SNES, PlayStation and N64. N64 uses ParaLLEl with the ARM64 libco context repair and the original Slot controls. Hold Menu for one second to quit to Slot.

The matching SYSTEM pair, complete corresponding source archive and manifest are backed up in the v0.1.8 GitHub Release. This tag preserves the stable frontend source; later commits add PSP/Dreamcast. Games and proprietary BIOS files are excluded. See docs/G350-0.1.8-UPDATE.md and docs/G350-0.1.8-VALIDATION.json.
